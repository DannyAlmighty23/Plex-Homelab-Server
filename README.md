# Plex Homelab Server

This is my personal Plex Media Server that I run and maintain from home.

I use it to manage my media library and share movies and TV shows with friends.

The server runs on **Windows 11**, and I handle the maintenance, updates, storage management, and Plex configuration myself.

## What I Use It For

The server is used for:

* Hosting movies and TV shows
* Streaming media through Plex
* Sharing my Plex library with friends
* Managing user access
* Testing remote streaming
* Managing available storage
* Monitoring server activity

## Server Maintenance

I normally check and update the server every week.

My regular maintenance includes:

* Checking for Plex Media Server updates
* Installing server updates
* Checking Windows updates
* Checking available storage
* Removing older movies when storage starts getting full
* Adding new movies or shows
* Checking that Plex is running correctly
* Monitoring server activity
* Checking for playback or streaming problems

## Media Requests

I also ask friends for movie and TV show recommendations.

When I get recommendations, I decide what to add to the server depending on available storage.

Since the server has limited storage, I periodically remove older content that is no longer being watched.

This has helped me learn how to manage storage instead of simply keeping everything permanently.

## Monitoring

I use **Plex Dash** to monitor activity on the server.

Plex Dash lets me see things such as:

* What is currently being streamed
* Which user is watching
* Playback activity
* Server usage
* Library activity
* Recent streams

I regularly check Plex Dash to make sure the server is working normally.

## Operating System

The server currently runs on:

**Windows 11**

I handle the operating system maintenance as well as Plex Media Server updates.

## Weekly Routine

A normal weekly check looks something like this:

1. Check Plex Media Server
2. Check for Plex updates
3. Check Windows updates
4. Check available storage
5. Review recent Plex activity
6. Look at movie or TV show recommendations
7. Add new content when needed
8. Remove older content if storage is getting full
9. Confirm remote streaming is working
